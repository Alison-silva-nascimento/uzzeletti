# UZZELETI — Moda Íntima

Site institucional da **UZZELETI Moda Íntima**, criado para apresentar coleções, produtos, novidades e os canais oficiais de atendimento da marca.

## Site online

[Acessar uzzeleti.com.br](https://uzzeleti.com.br)

## Sobre o projeto

O projeto é uma landing page estática, leve e responsiva. Não utiliza banco de dados, API ou backend: os dados dos produtos são mantidos localmente para uma publicação simples, rápida e segura.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
- JSON para os dados locais dos produtos e coleções
- GitHub Pages e Cloudflare Pages para hospedagem e entrega do site

## Estrutura principal

```text
assets/   Imagens, ícones e recursos visuais
css/      Estilos do site
data/     Produtos e coleções em JSON
js/       Funcionalidades em JavaScript
*.html    Páginas públicas do site
```

## Publicação

As alterações enviadas para a branch `main` são publicadas automaticamente. O domínio oficial é gerenciado pela Cloudflare:

- https://uzzeleti.com.br
- https://www.uzzeleti.com.br (redireciona para o domínio principal)

## SEO e segurança

O projeto inclui sitemap, robots.txt, URLs canônicas, metatags sociais e cabeçalhos de segurança para a hospedagem na Cloudflare.
